# Astronomy Data API

Educational astronomy API built with Python and FastAPI.

This project explores:

- modern backend engineering with FastAPI
- clean architecture principles
- scientific and astronomy datasets
- geospatial and astronomical APIs
- AI-assisted software development workflows

## Tech Stack

- Python 3.12
- FastAPI
- Pytest
- Ruff
- Uvicorn

## Goals

- Expose educational astronomy data through APIs
- Process real scientific datasets
- Build maintainable backend systems
- Explore scientific visualization and automation

## Running locally

```bash
uv sync
uv run uvicorn app.main:app --reload
